# Какие данные подготовить

Подготовь документы своей компании (.md, .pdf, .docx, .csv) и подключи их к агенту вместе с `instructions.md`.

**Методология (уже готова):**

- [`people-os.md`](../../../methodology/ru/people-os.md)
- [`ai-adoption-scan.md`](../../../methodology/ru/ai-adoption-scan.md)

**Данные компании, которые нужно подготовить:**

Описание компании: численность, структура, какие HR-документы уже есть (уровни, положение о вознаграждении, план адаптации), какие метрики считаются.

**Перед загрузкой.** Используй коды вместо имён, где это возможно, и проверь, что платформа соответствует требованиям компании к персональным данным.
