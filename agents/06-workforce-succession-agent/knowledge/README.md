# Какие данные подготовить

Подготовь документы своей компании (.md, .pdf, .docx, .csv) и подключи их к агенту вместе с `instructions.md`.

**Методология (уже готова):**

- [`workforce-planning.md`](../../../methodology/ru/workforce-planning.md)
- [`succession-planning.md`](../../../methodology/ru/succession-planning.md)

**Данные компании, которые нужно подготовить:**

1. План по выручке, средний чек, конверсия и медианная производительность по ролям (продажи, пресейл, внедрение).
2. Отток прошлого года, срок подбора и выхода на результат.
3. Список критичных ролей и потенциальных преемников.

**Перед загрузкой.** Используй коды вместо имён, где это возможно, и проверь, что платформа соответствует требованиям компании к персональным данным.
