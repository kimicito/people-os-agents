# 9-box grid

Сотрудники раскладываются по двум осям — **текущий результат** и **потенциал** — и попадают в одну из девяти ячеек. Это структура разговора руководителей между собой для решений о развитии и преемственности, а не отчёт наверх.

## Оси

- **Результат** — факты за период: цели, метрики.
- **Потенциал** — поведенческие индикаторы следующего уровня из модели компетенций.
- Каждая ось: низкий / средний / высокий. Без доказательств по **обеим** осям ячейка не ставится — «недостаточно данных».

## Что делать с каждой зоной

| Зона (результат / потенциал) | Кто там | Действие |
|---|---|---|
| Высокий / высокий | Будущие руководители и эксперты | Следующая роль, сложные задачи, удержание в приоритете |
| Высокий / средний | Опора команды | Удерживать и признавать; не путать с «нет перспектив» |
| Высокий / низкий | Эксперт | Ценить, не двигать вверх насильно |
| Средний / высокий | Недораскрытые | Разобраться, что мешает: роль, руководитель, обратная связь |
| Средний / средний | Основа команды | Развитие в текущей роли |
| Низкий / высокий | Не на своём месте | Выяснить причину: роль, руководитель, задачи |
| Низкий / низкий | Несоответствие роли | Честный разговор в ближайший месяц; часто дело в роли, а не в человеке |

Самая недооценённая ячейка — **высокий результат, низкий потенциал роста**: сильных специалистов регулярно портят повышением в руководители.

## Как проводить

1. Явно разделить результат и потенциал — смешивание превращает решётку в оценку симпатии.
2. Провести **калибровку между руководителями**: без неё оценки несравнимы. Показать распределение по руководителям и отметить перекосы.
3. Каждая ячейка заканчивается **действием**, а не ярлыком. Для нижних ячеек: 1–2 цели развития, поддержка, дата пересмотра (не позднее 6 месяцев).
4. Ячейка указывается **с датой**: это состояние, а не характеристика человека. Пересмотр раз в год или при смене роли.

## Где ломается

Оценка потенциала субъективна: его часто оценивают по сходству с оценивающим. Защита — поведенческие индикаторы из модели компетенций и калибровка. Слова «слабый», «бесперспективный», «балласт» не используются.
