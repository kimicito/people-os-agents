# Схема мотивации продавцов

Самый сильный документ управления продажами: **люди делают то, за что платят**, а не то, что написано в стратегии.

## Основные решения

| Решение | Варианты | Что покупаете |
|---|---|---|
| Доля переменной | 20–50% | Больше доля — выше риск и агрессивность |
| База начисления | Выручка, маржа, новые клиенты | От маржи — меньше скидок; от выручки — больше объёма |
| Порог | Выплата с 60–70% плана | Защита от случайных выплат, риск демотивации отстающих |
| Ускорители | Повышенный процент сверх плана | Стимул не останавливаться после выполнения |
| Момент выплаты | Подписание, оплата, отгрузка | По оплате — меньше кассовых разрывов и спорных сделок |

## Правила устойчивой схемы

- Продавец считает свой доход **сам, на салфетке**. Если нужна таблица — схема не мотивирует.
- Не больше **трёх показателей**.
- Схема **не меняется в середине периода**.
- Есть правило для нестандартных сделок, а не разбор каждой отдельно.

## Где схема работает против компании

- Платит за выручку при нулевой марже.
- Побуждает переносить сделки между периодами.
- Скидка не стоит продавцу ничего.

## Проверка по сценариям

| Выполнение плана | Оклад | Переменная | Итого | Комментарий |
|---|---|---|---|---|
| 70% | | | | Ниже порога? |
| 100% | | | | Целевой доход |
| 130% | | | | Работают ли ускорители? |
