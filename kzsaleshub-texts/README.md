## Структура

- `site/` — полный текстовый снимок базы знаний: 319 страниц (markdown, в каждом файле URL-источник)
  - 7 «систем»: `sales-os`, `ai-os`, `marketing-os`, `people-os`, `company-os`, `startup-os` (+обзор `os.md`)
  - 10 тематических разделов: продажи, операции, AI, финансы, лидерство, маркетинг, право, продукт, tech, HR
  - справочник: `frameworks`, `glossary`, `roles`, `tools`, `opensource`, `vendors`, `products`, `tech`, `industries`, `models`, `startups`
  - маршруты чтения (`marshrut-*`), обзоры вендоров (`kak-prodavat-*`), отрасли (`it-dlya-*`)
- `README.md` — этот файл
- `ATTRIBUTION.md` — атрибуция и правила использования

## Приёмочный разбор (ключевые приёмы — забираем архитектуру, тексты переписываем своими)

1. **«OS»-страницы**: «Коротко» в начале, таблица «этап → артефакт → показатель → где рвётся»,
   блок частых вопросов. Эталон — `site/ai-os.md` (уровни автономности, «частота × цена ошибки»,
   таблица «показатель / чем его подменяют» — анти-Гудхарт).
2. **Справочник с границами применимости** (`frameworks.md`) — фреймворки не списком, а с «когда НЕ работает».
3. **Маршруты чтения** (`marshrut-*.md`) — последовательности «читать сначала → потом» под роль.
4. **Теги поверх рубрик** — статьи числятся сразу в нескольких разрезах.
