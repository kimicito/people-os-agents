**Коротко.** Oracle продаёт базы данных, промежуточное программное обеспечение, корпоративные приложения и облако Oracle Cloud Infrastructure. Для большинства клиентов в регионе главная тема — база данных Oracle, на которой работают критичные системы банков, телекома и крупных компаний. Продавать Oracle — значит прежде всего грамотно считать лицензии: правила подсчёта процессоров, виртуализации и пользователей сложны, а ошибки обнаруживаются на аудите и стоят дорого. Партнёр, который помогает клиенту навести порядок в лицензиях и выбрать правильную архитектуру, становится для него доверенным советником.

## Логика вендора

База данных Oracle десятилетиями остаётся стандартом для систем, где важны надёжность, производительность и сложная обработка транзакций. На этой основе выстроен портфель: инструменты высокой доступности, промежуточное ПО, бизнес-приложения и облако, в котором Oracle предлагает свои продукты с выгодными условиями лицензирования.

## Портфель

| Направление | Что входит | Типичный повод |
| --- | --- | --- |
| База данных | Oracle Database в разных редакциях, опции и пакеты управления | Новые системы, рост нагрузки, обновление версий |
| Инженерные системы | Exadata и другие программно-аппаратные комплексы | Высокая производительность и консолидация баз |
| Облако OCI | Инфраструктура, управляемые базы данных, Autonomous Database | Перенос баз данных в облако, гибридные сценарии |
| Приложения | Fusion Cloud ERP, HCM, NetSuite для среднего бизнеса | Замена корпоративных систем |
| Java | Подписка Java SE | Использование Java в компании |

## Лицензирование базы данных: главное

*   **По процессорам.** Число лицензий зависит от числа ядер и коэффициента для типа процессора по таблице Oracle.
*   **По именованным пользователям.** С минимальным числом пользователей на процессор; подходит, когда пользователей мало и их можно точно посчитать.
*   **Редакции и опции.** Многие функции — секционирование, расширенная безопасность, пакеты диагностики — лицензируются отдельно. Включённая, но не купленная опция — частая находка аудита.
*   **Виртуализация.** Oracle признаёт не все виды разделения ресурсов. В некоторых средах виртуализации лицензировать приходится все физические серверы кластера, на которых может работать база, а не только используемые ядра.
*   **Облако.** Для публичных облаков действуют отдельные правила подсчёта; в собственном облаке Oracle условия обычно выгоднее.
*   **Поддержка.** Ежегодная поддержка составляет существенную долю от стоимости лицензий и требуется для получения обновлений.

Правила сложны и меняются. Перед каждым предложением расчёт стоит сверять с актуальными документами Oracle и специалистом по лицензированию.

## Java: отдельная тема

Oracle изменил модель коммерческой подписки на Java SE и перешёл к расчёту по общему числу сотрудников компании, а не по числу компьютеров, где установлена Java. Для многих компаний это изменило стоимость. Альтернатива — дистрибутивы OpenJDK от других поставщиков. Задача партнёра — помочь клиенту провести инвентаризацию: где и какая Java используется, требуется ли коммерческая лицензия.

## Аудит лицензий

Oracle регулярно проводит проверки использования лицензий у клиентов. Типичные находки:

*   использование опций, которые не были куплены;
*   неверный подсчёт процессоров в виртуальных средах;
*   базы данных на тестовых серверах без лицензий;
*   использование Java без подписки.

Лучшая защита — регулярная внутренняя инвентаризация. Для партнёра это хорошая услуга и точка входа к клиенту.

## Конкуренты и альтернативы

| Альтернатива | Когда рассматривают | Как отвечать |
| --- | --- | --- |
| PostgreSQL и другие базы с открытым кодом | Снижение стоимости лицензий | Оценить сложность миграции, совместимость приложений, требования к производительности и поддержке |
| Microsoft SQL Server | Экосистема Microsoft | Сравнить на конкретной нагрузке |
| Облачные управляемые базы других провайдеров | Переход в облако | Сравнить лицензирование Oracle в разных облаках и полную стоимость |

Миграция критичной базы данных с Oracle — серьёзный проект: хранимые процедуры, особенности SQL, производительность, поддержка приложений. Честная оценка помогает клиенту принять решение без сюрпризов.

## Где разговор ломается

*   Предложение без инвентаризации текущих лицензий и среды.
*   Не учтены правила виртуализации.
*   Включены опции, которые клиент не планировал покупать.
*   Не объяснена стоимость ежегодной поддержки.
*   Обещание лёгкой миграции на другую базу данных без анализа.

## Частые вопросы

Почему лицензирование Oracle в виртуальной среде так дорого?

Oracle признаёт не все технологии разделения ресурсов. В ряде сред приходится лицензировать все серверы, на которых теоретически может работать база данных. Архитектуру стоит проектировать с учётом этих правил.

Нужна ли коммерческая лицензия Java?

Зависит от используемых версий и дистрибутивов. Для коммерческой поддержки Oracle Java действует подписка; альтернативой являются сборки OpenJDK других поставщиков. Нужна инвентаризация.

Как подготовиться к аудиту Oracle?

Провести внутреннюю инвентаризацию: где установлены продукты, какие опции включены, как устроена виртуализация, какие лицензии куплены. Расхождения лучше найти самим.
