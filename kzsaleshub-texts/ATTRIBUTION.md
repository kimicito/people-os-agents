# Атрибуция и условия

**Автор контента:** Руслан Омаров, KZSalesHub (https://kzsaleshub.com/)
**Состав архива:** 319/319 страниц базы знаний (разделы, статьи, «системы»-OS, справочник, маршруты чтения), снято 2026-10-09. Покрытие полное по sitemap (проверено: missing=0).
**Разрешение:** тексты скопированы с согласия автора (договорённость Artur A. с Р. Омаровым, октябрь 2026).
**Не включено:** книги (`/knigi/`, `kniga-*`, `chitat-*`, «Команду продаж с нуля») — отдельные монографии,
на них разрешение не распространялось; страница менторства — служебная.

## Формат

- Каждый файл — markdown-выдача страницы: заголовок, URL-источник, дата публикации, текст.
- Имя файла = slug страницы (`site/people-os.md`, корень сайта → `site/index.md`).
- Снимок сделан через reader-сервис; интерактивные виджеты (Sales Audit, StageCheck) в markdown не сохраняются —
  в файлах остаётся их текстовое описание.

## Правила использования

1. Сохранять указание авторства при любом использовании (публикация, пересказ, цитирование).
2. Не выдавать тексты за свои; заимствования — с атрибуцией «Руслан Омаров, KZSalesHub».
3. Изменения в этом архиве — только добавления пометок, не правка исходного текста.
